# ربات تلگرام نرخ ارز و طلا 🇪🇺🇺🇸🪙

ربات خودکار انتشار نرخ **یورو، دلار، طلا و سکه** به تومان در یک کانال تلگرام.
داده‌ها از وب‌سرویس [navasan.tech](http://navasan.tech) گرفته می‌شود و **فقط وقتی قیمت تغییر کرده باشد** پیام جدید ارسال می‌شود.

بدون سرور — روی **GitHub Actions** رایگان اجرا می‌شود.

---

## ⚠️ مهم: محدودیت پلن رایگان نوسان

پلن رایگان نوسان فقط **۱۲۰ درخواست در ماه** می‌دهد = **روزی ۴ بار**.

| بازه اجرا | درخواست در ماه | پلن لازم |
|---|---|---|
| روزی ۴ بار | ۱۲۰ | ✅ رایگان |
| هر ۳۰ دقیقه (ساعات بازار) | ~۳۷۰ | 💳 پولی |
| هر ۱۵ دقیقه (ساعات بازار) | ~۷۴۰ | 💳 پولی |
| هر ۵ دقیقه ۲۴ ساعته | ~۸۶۰۰ | 💳 پولی |

«ارسال فقط هنگام تغییر قیمت» تعداد **پیام‌ها** را کم می‌کند، نه تعداد **درخواست‌ها** به API — چون برای فهمیدن تغییر باید هر بار API را صدا زد.

📧 برای پلن پولی: `webservice@navasan.net`

---

## راه‌اندازی در ۵ قدم

### ۱) کانال تلگرام و ربات

1. در تلگرام یک **کانال** بسازید (مثلاً `@my_rates_channel`).
2. به [@BotFather](https://t.me/BotFather) پیام دهید → `/newbot` → نام و یوزرنیم بدهید → **توکن** را کپی کنید.
3. ربات را در کانال **Admin** کنید با دسترسی *Post Messages*.
4. **شناسه کانال (Chat ID)**:
   - کانال عمومی → همان `@my_rates_channel`
   - کانال خصوصی → یک پیام در کانال بفرستید، سپس این آدرس را در مرورگر باز کنید:
     `https://api.telegram.org/bot<TOKEN>/getUpdates`
     عدد `chat.id` (چیزی شبیه `-1001234567890`) را بردارید.

### ۲) کلید API نوسان

از تلگرام‌بات [@navasan_contact_bot](https://t.me/navasan_contact_bot) کلید رایگان بگیرید.

### ۳) ساخت ریپازیتوری

یک ریپازیتوری **خصوصی** در گیت‌هاب بسازید و فایل‌های این پوشه را داخلش بگذارید:

```
bot.py
state.json
.gitignore
.github/workflows/rates.yml
```

### ۴) تنظیم Secrets

در ریپازیتوری: **Settings → Secrets and variables → Actions → New repository secret**

| نام | مقدار |
|---|---|
| `NAVASAN_API_KEY` | کلید API نوسان |
| `TELEGRAM_BOT_TOKEN` | توکن BotFather |
| `TELEGRAM_CHAT_ID` | `@channel_name` یا `-100...` |

همچنین **Settings → Actions → General → Workflow permissions** را روی **Read and write permissions** بگذارید (برای ذخیره‌ی آخرین قیمت‌ها).

### ۵) تست

تب **Actions** → ورک‌فلو «ارسال نرخ ارز به تلگرام» → **Run workflow**.
اولین اجرا همیشه یک پیام می‌فرستد.

---

## تنظیم بازه‌ی اجرا

در `.github/workflows/rates.yml` خط `cron` را عوض کنید (زمان‌ها **UTC** هستند؛ تهران = UTC + ۳:۳۰):

```yaml
# روزی ۴ بار — سازگار با پلن رایگان
- cron: '30 5,9,12,16 * * *'     # ۹:۰۰ ، ۱۲:۳۰ ، ۱۵:۳۰ ، ۱۹:۳۰ تهران

# هر ۳۰ دقیقه در ساعات بازار (شنبه تا چهارشنبه) — نیازمند پلن پولی
- cron: '0,30 5-14 * * 0-3,6'

# هر ۱۵ دقیقه، ۲۴ ساعته — نیازمند پلن پولی
- cron: '*/15 * * * *'
```

> نکته: زمان‌بندی گیت‌هاب اکشنز دقیق نیست و ممکن است تا چند دقیقه تأخیر داشته باشد. حداقل فاصله‌ی مجاز ۵ دقیقه است.

## تنظیمات دیگر (بخش `env` در ورک‌فلو)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `TRIGGER_ITEMS` | `eur,usd` | فقط تغییر این آیتم‌ها باعث ارسال پیام می‌شود. برای «فقط یورو»: `eur` |
| `MIN_CHANGE_PCT` | `0` | حداقل درصد تغییر برای ارسال. مثلاً `0.3` یعنی نوسان‌های زیر ۳ دهم درصد نادیده گرفته شوند |
| `UNIT_DIVISOR` | `1` | اگر دیدید قیمت‌ها ۱۰ برابر بزرگ‌اند (ریال)، این را `10` کنید |

برای حذف طلا و سکه از پیام، در `bot.py` سطرهای مربوطه را از لیست `SPEC` پاک کنید.

## اجرای دستی / تست محلی

```bash
# دیدن پیام بدون ارسال به تلگرام
DRY_RUN=1 NAVASAN_API_KEY=xxx python3 bot.py

# دیدن همه‌ی کلیدهای واقعی API (اگر آیتمی نمایش داده نشد)
NAVASAN_API_KEY=xxx python3 bot.py --list-keys

# تست کامل آفلاین با داده‌ی نمونه
DRY_RUN=1 python3 bot.py --sample sample.json
```

## رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `chat not found` | ربات را ادمین کانال کنید؛ Chat ID را دوباره بررسی کنید |
| `هیچ آیتم شناخته‌شده‌ای پیدا نشد` | `--list-keys` را اجرا کنید و کلیدها را در `SPEC` اصلاح کنید |
| پیام تکراری در هر اجرا | مطمئن شوید `state.json` کامیت می‌شود (Workflow permissions = Read and write) |
| هیچ پیامی نمی‌آید | طبیعی است اگر قیمت تغییر نکرده باشد — لاگ Actions را ببینید |
| ورک‌فلو بعد از ۶۰ روز غیرفعال شد | گیت‌هاب ریپازیتوری‌های بی‌فعالیت را متوقف می‌کند؛ از تب Actions دوباره Enable کنید |
